# BrazeUp - Metal Defect Detection API

A FastAPI application for detecting metal surface defects using deep learning.

## Features
- Upload images for defect detection
- Inspection form submission
- Case management dashboard

## Endpoints
- `/form` - Inspection submission form
- `/dashboard` - Case management dashboard
- `/api/analyze` - Image analysis endpoint
- `/docs` - API documentation
